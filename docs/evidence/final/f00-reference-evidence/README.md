# Portable F00 reference evidence

This directory is the Git-portable replacement for the ignored
`.omx/plans/f00-reference-evidence/` handoff that the original final audit
referenced. `manifest.json` preserves the 69 exact story/node/referenceJSON
records embedded in `Tests/Fixtures/StoryFixtureData.swift` and records the
SHA-256/dimensions of all 69 exact Figma frame exports.

The 44 exports that were absent from the current worktree were re-downloaded
from the connected Figma MCP on 2026-09-24; the remaining 25 are byte-identical
copies of their retained story evidence. This is reference evidence only: it
is not an implementation capture, visual-pass claim, accessibility claim, or
production-effect proof.
